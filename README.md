# Regency Travel House | Front-end

## Getting Started

These instructions will help you set up the project locally.

1. **Clone the repository:**

   ```bash
   git clone https://github.com/devashanv/regency_travel_house_front_end.git

2. **Navigate into the project directory**
   ```bash
   cd <project-folder>

3. **Install dependencies:**
    ```bash
   npm install

4. **Run the development server:**
    ```bash
   npm run dev
   

   The application will be available at http://localhost:3000.

## Team Collaboration
- main branch: This is the production-ready branch. Do not diretly push to this branch.

- dev(development) branch: This is the integration branch where feature branches are merged. Push your development to this branch.

- Feature branches: Create a new branch from develop for any new feature. Naming convention: feature/integrate-feature-name.

### ✅ Contribution Guidelines  
**Always work on a new branch** (avoid committing directly to `main`).  
**Write clear commit messages** (e.g., `Added login page`).  
**Pull latest changes before working** to avoid conflicts.  
**Review and test code** before pushing.
